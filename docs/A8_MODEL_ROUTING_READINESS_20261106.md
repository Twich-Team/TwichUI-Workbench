## Codex access and authorization

The installed CLI reports version 0.166.0. The previous local receipt established ChatGPT login for the development launcher. The Workbench service has no configured Codex executor, credential binding or network route for Codex. The installed CLI and prior login provide no evidence of this account's automated access, eligible model, available allowance or a spending ceiling. This review used official documentation and local inspection without invoking either provider.

OpenAI documents `codex exec` for noninteractive jobs and the SDK or app-server for programmatic integrations. The documentation recommends API-key authentication for programmatic CLI use. It separately describes managed ChatGPT authentication for trusted private automation, with restrictions, and enterprise access tokens where an administrator grants permission. Confirm a supported route for the actual account and repository before implementation is enabled.
