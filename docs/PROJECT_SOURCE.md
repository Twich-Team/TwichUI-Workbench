# Project source and preserved results

The research checkout is a preserved input, not a promise that its old `main`
is current. The November 9 real-use investigation found that the installed
checkout preceded the reported feature. Current source is now selected from
verified immutable snapshots under its private `.git/workbench-source` registry.
The original checkout, its Git configuration and its recoverable bundle remain
unchanged. Current status and private verification receipts are in CONTINUATION.

Before a fresh ordinary investigation, the worker requests a fixed public read
of `https://github.com/Twich-Team/TwichUI.git`, branch `main`. An ephemeral user
service runs the fixed downloader as Rich in a credential-free bubblewrap
environment. Its writable mount is only the source registry; the owner's home,
credentials, application database, connector socket and model keys are absent.
It has no task-selected command, URL or path, cannot push, does not run downloaded
code, and disables Git hooks, helpers, global configuration and submodules.
The persistent worker's loopback-only network policy is unchanged. No new root
grant or persistent service is introduced. The download has operation, memory,
process, output, storage and free-space bounds; failed refreshes preserve the
published snapshot and wait with backoff before any model call.

Each investigation remains bound to its committed revision. Refreshing a
settled unapproved task uses a separate read-only clarification action on the
same saved request. It retains all phases and usage and starts a new source
context without carrying stale code or unverified findings forward. It does
not approve a plan, execution or publication, change the provider, or enable
fallback. Older proposals remain readable but cannot authorize work on the
new revision. Existing operation bounds and actual service limits still apply;
superseded delivery campaign caps do not.

Already checked results may resolve their exact original source only after the
stored finished execution, grant, task and approval bindings are verified.
This compatibility path cannot activate an unexecuted older approval. Existing
candidate checks and scope checks still apply. Retain referenced source
snapshots; do not prune them as generic download caches.

Missing source must hold new source-dependent work, while history and unrelated
demo records remain readable. Advanced evidence retains all references even
when the summary displays a bounded selection.
