# Synthetic guide tracking example

`guide-status.json` is an authored, deterministic product example. It is not actual
addon research, an implementation result, or verified feasibility. Its request goes
through the same intake API, durable planning job, proposal, artifact, human-decision
and decomposition contracts as other local requests. Minimal existing demos remain.

`guide-status-mockup.svg` and `guide-status-context.svg` are repository-native vector
illustrations written for this fixture. Their PNG derivatives were rendered locally
with the installed Chromium browser. No external image-generation service, game
capture, simulator, player data or copied Workbench section artwork was used.
Both images visibly say they are synthetic and not implemented/game evidence.

The context image satisfies only the explicitly synthetic workflow fixture's image
role. A real visual proposal still needs a representative in-game-context reference
and human review of its relevance. Neither an image role nor a passed fixture test
establishes the authenticity of a real-game artifact.
